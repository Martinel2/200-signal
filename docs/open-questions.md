# 미확정 사항과 원문 충돌

## 구현 전에 반드시 결정

### 가격과 SMA

- SMA200 계산에 원종가 또는 수정종가 중 무엇을 사용할 것인가?
- 분할 발생일 전후에 데이터 제공자별 SMA 차이를 어떻게 처리할 것인가?
- 데이터 제공자가 과거 값을 수정했을 때 기존 신호 기록을 보존할 것인가?

### 매수 체결

- 상향 돌파 종가 확인 후 1일 차 매수를 애프터마켓에서 실행하는가?
- 2·3일 차도 각 종가 확인 후 애프터마켓에서 실행하는가?
- 1일 차를 놓치고 2·3일 차에 처음 확인한 사용자는 어떻게 진입하는가?
- 애프터마켓이 불가능하면 다음 정규장 시가로 미루는가?
- 시장가와 지정가 중 무엇을 안내하는가?

### 매도 체결

- 원문은 애프터마켓 매도를 지시하지만 증권사별 지원 시간이 다르다.
- 미국 서머타임·표준시·조기폐장·휴장을 반영해야 한다.
- 애프터마켓 유동성 부족 시 다음 정규장까지 기다릴지 결정해야 한다.

### 수익률

- 환율 반영 수익률에 실제 매수환율과 현재환율을 사용하는가?
- 환전 수수료, 거래 수수료, 예상 세금을 포함하는가?
- 부분익절 실현금액을 이후 +25%, +50% 수익률 계산에 포함하는가?
- 여러 계좌에 분산된 TQQQ의 수익률을 합산할 것인가?

### 익절 수량

- 정수 수량을 반올림, 내림 또는 소수점 주문 중 무엇으로 처리하는가?
- 한 번에 여러 문턱을 넘으면 각 단계를 순차 적용하는가?
- 기존 계좌를 앱에 처음 등록했을 때 지나간 단계를 어떻게 소급하는가?

### 신규 자금

- '목돈'과 '소액'의 경계가 정의되지 않았다.
- ENTRY 진행 중 들어온 신규 자금을 어디에 둘지 명확하지 않다.

## 원문 내 충돌과 현재 해석

### SPYM의 하향 이탈 처리

- 한 설명: TQQQ 청산 후 SPYM·SGOV는 그대로 유지
- 더 구체적인 반복 설명: SMA200 이탈 시 SPYM도 전량 매도하고 SGOV로 전환
- 현재 해석: 후자를 공식 규칙으로 채택

### 누적 익절 20%·30%

- 정규 규칙: 각 단계에서 남은 수량의 10%
- 후발 보유자 지침: +25%이면 현재 수량 20%, +50%이면 현재 수량 30%
- 현재 해석: 정규 운용은 단계별 계산. 후발 계좌 처리 방식은 별도 UX로 제공.

### 대익절의 끝

- 일부 글: +100%, +200%, +300%
- 행동 매뉴얼: +300% 이후 계속
- 현재 해석: +100%부터 +100% 간격으로 계속

### 합성 데이터 비용

- 공식 이미지 설명: 0.5% + 0.86%
- 비교 설명: 운용보수 0.95%, 스왑 스프레드 0.5%
- 현재 해석: 원자료와 코드를 확인하기 전 미확정

### 백테스트 승률과 기대값

- 제시된 승률·평균손익은 음의 산술 기대값
- 제시된 장기 결과는 큰 양의 수익
- 현재 해석: 통계 정의 또는 본문 숫자에 오류가 있을 가능성이 있어 원거래 기록 필요

## 제품 범위에서 결정

- 신호 안내만 제공할지, 브로커 주문 연결까지 할지
- 한국 사용자만 대상으로 할지
- 계좌정보를 수동 입력할지, 증권사 연동을 사용할지
- 실시간 시세가 필요한지, 종가 데이터만 사용할지
- CNN 공포탐욕지수를 후발 진입 기능에 포함할지
- RSI 조건을 기본 전략이 아닌 선택형 보조지표로 제공할지
- 세금 예상 기능을 어느 수준까지 제공할지

## 권장 초기 결정

- MVP는 주문 자동실행 없이 신호와 계산 수량만 제공
- 원문 재현 모드와 사용자 변형 모드 분리
- 핵심 신호는 일별 확정 종가만 사용
- 보조지표와 후발 진입은 핵심 전략과 분리
- 실제 데이터 구간의 백테스트를 먼저 구현
- 합성 구간은 원자료와 생성 코드를 확보한 뒤 추가
