# 200큐큐단(베타) 감시 명세

## 1. 출처와 목적

- 출처: [FMKorea 원문](https://www.fmkorea.com/10178630148), 사용자 제공 전문
- 이름: 기존 TQQQ SMA200 전략은 **알파(200티큐단)**, 이 문서의 전략은 **베타(200큐큐단)**
- 목적: 두 전략의 상태를 서로 섞지 않고 계산하되 앱의 `오늘의 신호`, 알림, 위젯 한 곳에서 함께 표시한다.
- 앱은 주문을 실행하지 않는다. 모든 신호는 실제 체결 전 증권사 데이터로 다시 확인한다.

## 2. 자산과 기준

| 역할 | 자산/값 |
|---|---|
| 추세 판정 | QQQ 확정 일봉 종가와 SMA200 |
| 공격 자산 | TQQQ |
| 익절·TS 전환 자산 | SPYM |
| 사이클 밖 대기 | SGOV |
| 진입선 | `QQQ SMA200 × 1.02` |
| 이탈선 | `QQQ SMA200 × 0.98` |

밴드는 두 개의 독립 교차선이 아니라 히스테리시스다.

- 사이클 밖에서 QQQ 종가가 상단선을 상향 돌파하면 `ABOVE` 사이클을 시작한다.
- 사이클 안에서는 QQQ가 밴드 안으로 돌아와도 보유한다.
- QQQ 종가가 하단선 아래로 내려가면 사이클을 끝낸다.
- 사이클 밖에서 밴드 안에 있는 경우에는 SGOV에서 다음 상단 돌파를 기다린다.

## 3. 진입

상단 돌파일부터 미국 거래일 기준 3회에 나눠 TQQQ를 매수한다.

1. 1차: 최초 진입자금의 1/3
2. 2차: 남은 진입자금의 1/2
3. 3차: 남은 진입자금 전액

각 차수는 별도 거래일이다. 3분할 도중 하단선을 이탈하면 보유 TQQQ와 SPYM의 전량 매도 및 SGOV 전환 신호가 우선한다.

## 4. 부분익절

수익률 기준은 환율을 섞지 않은 TQQQ 달러 평단 대비 수익률이다.

| 구분 | 도달 수익률 | 매도 비율 |
|---|---|---|
| 소익절 | +10%, +25%, +50% | 각 시점의 TQQQ 잔고 10% |
| 대익절 | +100%, +200%, +400%, +800%… | 각 시점의 TQQQ 잔고 50% |

- 각 단계는 사이클당 한 번만 발동한다.
- 매도한 금액은 SPYM으로 전환한다.
- 앱의 시장 감시는 3회 동일 금액을 확정 종가에 체결했다고 가정한 참고 평단을 사용한다.
- 실제 계좌의 체결가·수량과 다른 경우 참고 신호와 실제 주문 수량이 달라질 수 있다.

## 5. 트레일링 스탑(TS)

- 기준: 현재 상승 사이클의 TQQQ 최고가 대비 −25%
- 행동: 현재 TQQQ 잔고의 50%를 SPYM으로 전환
- 횟수: 원문의 “최초 1번 정도”를 사이클당 최초 1회로 해석한다.
- TS 이후에도 QQQ가 하단선을 이탈하기 전까지 사이클은 `ABOVE`로 유지한다.
- 앱은 확정 일봉 종가로 TS를 재현하고, 현재 장중 TQQQ 가격이 선을 건드리면 확정 전 예비 경고만 표시한다.

## 6. 상태와 당일 우선순위

```text
DATA_ERROR
SAFE
ENTRY_DAY_1
ENTRY_DAY_2
ENTRY_DAY_3
RISK_ON
TAKE_PROFIT
TRAILING_STOP
EXIT_PENDING
```

같은 날 조건이 겹치면 다음 순서로 한 개의 대표 행동을 표시한다.

1. 하단 이탈 전량 대피
2. 1·2·3차 진입
3. TS 50% 전환
4. 부분익절
5. 보유 또는 대기

## 7. 알파와의 분리

| 항목 | 알파(200티큐단) | 베타(200큐큐단) |
|---|---|---|
| 추세 입력 | TQQQ / TQQQ SMA200 | QQQ / QQQ SMA200 ±2% |
| 상태 계산 | 기존 `deriveRegime` | 별도 `deriveBetaSnapshot` |
| TS | 없음 | TQQQ 사이클 고점 대비 −25% |
| 대익절 | 기존 선형 단계 | 2배 등비 단계 |
| 표시 | 오늘의 신호 화면 | 같은 화면의 별도 카드 |

한 전략의 상태가 다른 전략의 진입·이탈 상태를 바꾸지 않는다. 기존 알파 거래 원장도 베타의 참고 평단 계산에 사용하지 않는다.

## 8. 원문만으로 확정할 수 없는 항목

- 신호 당일 종가 체결인지 다음 거래일 시가 체결인지
- 장중 TS 터치 후 종가 회복도 발동으로 보는지
- TS 후 새 고점을 만들었을 때 두 번째 TS를 허용하는지
- 동일 거래일에 여러 익절 단계를 건너뛴 경우의 실제 체결 순서
- 장기 백테스트의 TQQQ 합성 가격과 SPYM 대체 시계열 산식

앱은 위 항목을 임의의 자동주문 규칙으로 확대하지 않는다. 현재 구현은 확정 종가 기반 참고 감시이며, 원문 또는 백테스트 코드가 확보되면 이 문서를 먼저 고친 뒤 엔진을 맞춘다.
