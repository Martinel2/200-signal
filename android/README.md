# 200 SIGNAL Android

안드로이드 네이티브 앱입니다. 앱이 직접 인터넷에서 일별 시세를 받아 기기 안에서 SMA200과 전략 상태를 계산합니다.

## 동작

- 앱 시작 시 자동 시세 갱신
- 앱을 다시 열 때 캐시가 30분보다 오래됐으면 자동 갱신
- 인터넷이 다시 연결되면 자동 재시도
- 수동 새로고침
- 약 15분 주기의 백그라운드 확정 신호·부분익절 단계·장중 예비 경고 알림
- Android 알림 권한, 채널 분리, 중복 방지, 테스트 알림
- TQQQ 1분봉 기반 프리장·정규장·애프터장 참고 시세
- 장중 가격의 SMA200 예비 위치와 반대 방향 예비 경고
- TQQQ, QQQ, SPYM, SGOV, USD/KRW 조회
- 알파(TQQQ SMA200)와 베타(QQQ SMA200 ±2%·TQQQ TS) 독립 감시 및 통합 표시
- 최근 200거래일 SMA 계산
- 진입 1·2·3일 차, 보유, 대피 상태 판정
- 마지막 성공 데이터 오프라인 캐시
- 거래별 매수·매도 체결가, 당시 환율과 수수료 원장
- 퍼센트 수수료율 저장 및 다음 거래 자동 적용
- 매도 완료 전 순입금·실현손익 미리보기와 완료 후 거래별 정산 표시
- 도달한 다음 익절 단계의 전략 수량과 현재 참고가로 원터치 자동 기록
- 대표 퍼센트는 현재 사이클의 실현손익과 평가손익을 합산
- 내 계좌 최상단에 확정 종가와 계좌를 합친 `지금 할 일` 표시
- 확정 종가 차트 길게 누르기·드래그로 날짜별 종가와 SMA200 표시
- 장중 등락률 옆에 전일 확정 종가와 비교 기준 표시
- 기존 부분익절 실현손익, 남은 원가, 평가손익, 총손익 계산
- 다른 해외주식 손익을 합산한 연간 예상 양도소득세
- 완료 익절 단계와 거래 원장을 기기에만 저장
- 미국 정규장 종료 후 5분이 지난 일봉만 확정 종가 신호에 사용
- 전량 매도 후 재진입 시 익절 완료 단계를 새 사이클로 초기화
- 첫 실행 시 신호·거래 원장·주문 후 기록 과정을 설명하는 4단계 안내
- 가이드 탭의 버튼 설명, 실제 입력 예시, 11장 전체 전략 가이드북
- 신호 화면 최상단 확정 종가 그래프와 역할별 상태 색상
- 의미·완료 여부·확인창을 갖춘 부분익절 단계 버튼

## 빌드

필요 환경:

- JDK 17
- Android SDK Platform 37
- Android SDK Build Tools 36.0.0 이상
- Gradle 9.6.1

```bash
./gradlew test
./gradlew assembleDebug
```

디버그 APK:

```text
app/build/outputs/apk/debug/app-debug.apk
```

## 데이터

현재 Yahoo Finance 비공식 Chart API를 앱에서 직접 호출합니다. 실제 출시 전에는 약관과 안정성이 명확한 정식 데이터 공급자로 교체해야 합니다.

인터넷이 없거나 API 호출이 실패하면 매매 신호를 추측하지 않고 마지막 성공 데이터를 캐시로 표시합니다. 캐시도 없으면 신호를 표시하지 않습니다.

세부 기능과 계산 방식은 [FEATURES.md](FEATURES.md)를 참고하세요.
