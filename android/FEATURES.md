# Android 앱 기능과 계산 방식

## 1. 데이터 수집

앱이 별도 웹 서버 없이 외부 API를 직접 호출한다.

| 데이터 | 조회 범위 | 용도 |
|---|---|---|
| TQQQ 일봉 | 2년 | SMA200과 확정 전략 신호 |
| TQQQ 1분봉 | 당일·시간외 포함 | 장중 참고가와 예비 경고 |
| SPYM 일봉 | 최근 5일 | 익절금 전환 참고가격 |
| SGOV 일봉 | 최근 5일 | 대피자산 참고가격 |
| USD/KRW 일봉 | 최근 5일 | 환율 반영 계좌 수익률 |

다섯 요청은 동시에 실행해 갱신 시간을 줄인다.
TQQQ 확정 일봉은 필수이며 SPYM·SGOV·환율·장중 시세는 서로 독립적으로
실패를 처리한다. 보조 데이터 하나가 실패해도 확정 SMA200 신호는 계속 갱신한다.

## 2. 자동 갱신

- 앱 최초 실행 시 인터넷이 있으면 자동 조회
- 앱을 다시 열 때 마지막 조회가 30분 이상 지났으면 자동 조회
- 네트워크 연결이 복구되면 자동 조회
- 상단 새로고침 버튼으로 강제 조회
- 중복 네트워크 요청은 하나만 실행

## 3. 백그라운드 신호 알림

- 사용자가 신호 화면에서 직접 켜고 끌 수 있음
- 인터넷 연결이 있을 때 WorkManager가 최소 약 15분 주기로 백그라운드 조회
- 확정 종가 신호 상태가 바뀌면 높은 중요도의 알림 전송
- 장중 가격이 확정 종가 기준 SMA200 반대편으로 넘어가면 별도 예비 경고
- 확정 신호와 장중 예비 경고를 Android 알림 채널에서 각각 제어 가능
- 동일 상태 또는 동일 방향의 장중 경고는 반복 발송하지 않음
- 거래 원장의 환율·수수료 반영 보유분 수익률이 새 익절 단계에 도달하면 알림
- 최초 조회는 현재 상태를 기준점으로만 저장하여 오래된 신호를 발송하지 않음
- 테스트 알림 버튼 제공
- Android 13 이상에서 `POST_NOTIFICATIONS` 런타임 권한 요청
- 시스템에서 모든 알림 채널을 막으면 앱에서 Android 알림 설정으로 이동

Android의 배터리 최적화와 Doze 정책 때문에 15분은 보장된 정확한 시각이 아니며
실행이 늦어질 수 있다. 이 기능은 서버가 보내는 FCM 원격 푸시가 아니라 기기가
직접 API를 확인해 만드는 로컬 백그라운드 알림이다.

## 4. 장중 참고 시세

- TQQQ 1분봉의 마지막 유효 체결가 사용
- 프리마켓·정규장·애프터마켓·장 마감 상태 구분
- 전일 종가 대비 등락률 표시
- 확정 SMA200 대비 장중 이격률 표시
- 확정 신호와 장중 방향이 반대면 예비 경고
- 공급자가 제공한 지연 초 표시

장중 참고가는 매매 신호가 아니다. 앱 화면에서도 확정 신호 카드와 분리한다.

## 5. 확정 전략 신호

최근 200거래일의 TQQQ 일반 종가로 단순이동평균을 계산한다.

Yahoo 일봉에는 장중에 아직 끝나지 않은 당일 캔들이 포함될 수 있으므로, 미국
정규장 종료 시각에서 5분이 지난 뒤에만 당일 일봉을 확정 데이터에 포함한다.
장중 캔들은 장중 참고 카드와 예비 경고에만 사용한다.

```text
SMA200[t] = close[t-199...t]의 평균
```

| 상태 | 조건 |
|---|---|
| 1차 진입 | 전일 종가 ≤ 전일 SMA200, 최근 종가 > 최근 SMA200 |
| 2차 진입 | 상향 돌파 다음 거래일에도 SMA200 위 |
| 3차 진입 | 상향 돌파 후 두 번째 거래일에도 SMA200 위 |
| TQQQ 보유 | 3분할 이후 종가가 SMA200 위 |
| 대피 신호 | 전일 종가 ≥ 전일 SMA200, 최근 종가 < 최근 SMA200 |
| SGOV 대기 | 종가가 SMA200 아래이며 당일 신규 이탈은 아님 |
| 경계 대기 | 종가와 SMA200이 정확히 같음 |
| 데이터 오류 | 유효 일봉이 201개 미만이거나 계산 불가 |

행동 제안:

- 1차: 가용 진입자금 1/3
- 2차: 남은 진입 현금 1/2
- 3차: 남은 진입 현금 전액
- 하향 이탈: TQQQ·SPYM 청산 후 SGOV 전환 검토

## 6. 차트

- 최근 최대 260거래일 표시
- TQQQ 종가선과 SMA200을 동시에 표시
- 화면에서 그리며 별도 차트 라이브러리를 사용하지 않음

## 7. 거래 원장과 계좌 계산

각 매수·매도 거래에 다음 값을 입력한다.

- 체결일
- 매수 또는 매도(부분익절 포함)
- 체결 수량
- 달러 체결가
- 체결일 적용 USD/KRW 환율
- 원화 환산 매매 수수료
- 정수 또는 소수점 주문
- 이미 완료한 익절 단계

원화 이동평균 원가 방식:

```text
매수 원가 = 수량 × 달러 체결가 × 매수일 환율 + 매수 수수료
매도 대금 = 수량 × 달러 체결가 × 매도일 환율 − 매도 수수료
매도 실현손익 = 매도 대금 − 매도수량에 배분된 원화 이동평균 원가
현재 평가금 = 남은 수량 × 현재 TQQQ 가격 × 현재 USD/KRW
평가손익 = 현재 평가금 − 남은 원가
총손익 = 누적 실현손익 + 평가손익
```

전량 매도 뒤 다시 시작한 경우 익절 기준용 사이클 수익률은 새 사이클부터 다시 계산한다.
이미 실행한 부분익절을 매도 거래로 넣으면 실현손익, 남은 원가, 현재 사이클
수익률에 이어서 반영한다.

부분익절 단계 판정에는 실현대금을 섞은 사이클 총수익률이 아니라 현재 남은
보유분의 원화 평가금 ÷ 원화 잔여원가 − 1을 사용한다. 전량 매도 후 새 매수를
등록하면 과거 사이클의 완료 단계는 자동 초기화한다.

### 예상 양도소득세

현재 연도에 매도한 TQQQ 실현손익과 사용자가 입력한 다른 해외주식 연간
실현손익을 통산한다.

```text
합산손익 = 올해 TQQQ 실현손익 + 다른 해외주식 실현손익
과세표준 = max(0, 합산손익 − 2,500,000원)
국세 = 과세표준 × 20%
지방소득세 = 과세표준 × 2%
예상세액 = 과세표준 × 22%
```

이는 신고 보조용 예상치다. 실제 증권사별 취득가액 산정, 환율, 비용 인정,
다른 계좌 손익 및 세법상 예외는 증권사 양도소득 자료와 세무 신고 결과가 우선한다.

익절:

- +10%, +25%, +50%: 남은 수량의 10%
- +100%, +200%, +300% 이후 매 +100%: 남은 수량의 50%
- 완료 체크된 단계는 반복하지 않음
- 여러 단계를 건너뛰면 낮은 단계부터 순서대로 남은 수량을 다시 계산
- 정수 주문은 원문 예시에 맞춰 0.5 이상 올림 반올림
- 소수점 주문은 소수점 6자리

## 8. 로컬 저장과 오프라인

- 거래 원장, 다른 해외주식 손익, 익절 완료값은 Android SharedPreferences에만 저장
- 금융 원장 보호를 위해 Android 클라우드 백업 대상에서 앱 데이터를 제외
- 서버로 계좌정보를 전송하지 않음
- 마지막 성공 시장 스냅샷과 차트를 기기에 캐시
- 오프라인이면 캐시임을 표시
- 캐시가 없으면 신호를 생성하지 않고 인터넷 연결을 기다림
- 장중 조회만 실패해도 일봉 확정 신호는 계속 표시

## 9. 화면

### 첫 실행 안내

- 앱이 자동 주문하지 않는다는 점을 먼저 설명
- 신호 화면의 새로고침·장중 참고·확정 신호·알림 버튼 안내
- 내 계좌의 매수·매도 원장 입력 순서 안내
- `신호 확인 → 내 계좌 수량 확인 → 증권사 직접 주문 → 체결 원장 입력` 반복 흐름 안내
- 한 번 완료한 뒤에도 가이드 탭에서 다시 실행 가능

### 신호

- 제목 직후 확정 종가 그래프를 가장 먼저 표시
- TQQQ 종가는 파랑, SMA200은 주황으로 구분
- 진입은 파랑, 보유는 청록, 대피는 빨강, 대기는 보라 계열로 구분
- 장중 참고 시세
- 백그라운드 알림 설정·예비 경고 설정·테스트 알림
- 거래 원장 기반 부분익절 단계 도달 알림
- 확정 종가 전략 신호
- TQQQ 종가·SMA200·이격률
- 최근 차트
- 데이터 시각과 캐시 여부

### 내 계좌

- 매수·매도·체결가·당시 환율·수수료 거래 원장
- 현재 보유수량·남은 원가·평가손익·기존 부분익절 실현손익·총손익
- 다른 해외주식 손익통산과 예상 양도소득세
- 익절 단계 완료 체크
- 단계 버튼에 `미완료`/`완료` 상태를 직접 표시
- 활성 포지션이 없으면 단계 버튼 비활성화
- 실제 매도·원장 기록 여부를 재확인하는 완료 변경 확인창
- 현재 사이클의 수수료·환율·부분익절 반영 수익률
- 현재 시장 상태를 우선한 행동 제안
- 단계별 예상 매도수량

### 가이드

- 버튼을 누르면 무엇이 바뀌는지 설명하는 버튼 지도
- 알림을 받고 실제 매도한 뒤 원장을 갱신하는 완성 예시
- 왜 투자하는지부터 세금·앱 한계까지 11장으로 정리한 접이식 가이드북
- SGOV 대기, 3일 분할매수, 단계별 익절, 하향 이탈 대피
- 신규 자금, 신규 진입자, 인출 순서, 대출 금지
- 합성 데이터와 장기 MDD 등 백테스트 한계

## 10. 포함하지 않은 기능

- 자동 주문
- 증권사 계좌 연동
- 초 단위 백그라운드 상시 실시간 스트리밍
- 서버 기반 FCM 원격 푸시
- 증권사 세무자료 자동 연동 또는 세금 신고
- 공식 유료 시세
- 독립 검증된 장기 백테스트

현재 Yahoo Finance 비공식 API를 사용하므로 지연·누락·차단 가능성이 있다. 실제 출시용 앱은 정식 데이터 공급자가 필요하다.
