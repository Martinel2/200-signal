# TQQQ 200일선 신호 앱

FMKorea의 '아기티큐 TQQQ 200일선 매매법'을 가이드북과 매매 신호 앱으로 정리하는 프로젝트입니다.

현재 단계에서는 사용자가 제공한 원문을 바탕으로 전략을 구조화했습니다. 문서에 적힌 수익률과 통계는 원문 작성자의 주장과 자체 검증 결과를 구분합니다.

## 중요한 원칙

- 이 프로젝트는 투자 자문이나 수익 보장 서비스가 아니다.
- 실제 주문을 자동 실행하기 전에는 데이터, 주문 시점, 세금 및 증권사별 거래 가능 시간을 별도로 검증해야 한다.
- 원문 전략 재현 모드와 사용자가 바꿀 수 있는 변형 전략을 분리한다.

## Android 앱

설치 가능한 APK:

- [200 SIGNAL v0.38 디버그 APK](https://github.com/Martinel2/200-signal/releases/tag/v0.38)

지원 범위:

- Android 7.0(API 24) 이상
- 앱 실행·재개 시 자동 시세 갱신
- 인터넷 연결 복구 시 자동 재시도
- 마지막 성공 데이터 오프라인 캐시
- 기기 내부 SMA200·진입·보유·대피 계산
- 알파(TQQQ SMA200)와 베타(QQQ SMA200 ±2%·TQQQ TS)를 독립 계산해 한 신호 화면에 표시
- 총자산만 입력하면 실시간 참고가로 종목별 매수금액·수량 자동 계산
- 공통 거래 원장의 기존 보유수량을 차감해 실제 조정수량 계산
- TQQQ·SGOV·SPYM 공통 거래 원장과 통합 계좌·자동 주문 카드
- 계산된 TQQQ·SGOV·SPYM 주문을 해당 종목 매수·매도 거래로 즉시 등록
- 추가 현금은 원화 또는 달러로 입력하고 당시 환율과 환산 USD를 함께 기록
- 모든 자동 주문은 정수 주식으로 계산하고 절삭 잔액은 현금으로 유지
- 수동 매도 선택 시 해당 종목의 전체 보유수량을 수량칸에 자동 입력
- TQQQ 분할진입 등록 시 필요한 SGOV 매도도 공통 원장에 함께 등록
- 정수 주문수량 계산에 매수·매도 수수료를 포함해 현금 초과 사용 방지
- 홈 화면 위젯에서 계좌 연동 CURRENT ACTION·오늘 정수 주문·TQQQ/SMA200 표시
- 위젯 15분 주기 갱신, 즉시 새로고침, 탭하여 앱 열기
- 위젯 새로고침 중 로딩 표시와 최근 60거래일 TQQQ·SMA200 미니 차트
- 총자산은 읽기 전용 표시 후 수정·저장·취소 절차로만 변경
- 거래내역 수정으로 분할매수 실제 체결수량·체결가·평단·다음 차수 재계산
- SMA200 아래 SGOV 100%, 기존 상승 구간 SGOV·SPYM 50:50 신규 자금 배분 계산
- TQQQ 미보유 계좌는 상향 돌파 1일 차에만 정규 TQQQ 신규진입 시작
- TQQQ 0주·SMA200 위 계좌는 사용자 확인 없이 SGOV·SPYM 50:50 자동 적용
- 신호 화면 CURRENT ACTION도 실제 TQQQ 보유수량에 따라 계좌 행동 표시
- SGOV·SPYM 보유수량과 사용 가능 현금을 반영한 실제 조정수량 계산
- 상향 돌파 1차는 전체 가용자금 1/3, 2차는 실제 잔액 1/2, 3차는 실제 잔액 전액 계산
- 1·2·3차 TQQQ 실제 체결을 거래 원장과 연결해 다음 차수 잔액 계산
- 상향 돌파 후 3거래일 TQQQ 1/3 분할매수 금액·참고수량·누적 목표 계산
- 거래별 달러 체결가와 달러 수수료를 반영한 USD 계좌 원장
- 한 번 저장하면 다음 거래에도 적용되는 퍼센트 수수료율
- 매도 전 순입금액·실현손익 미리보기와 거래별 정산 기록
- 도달한 익절 단계의 수량·달러 가격·수수료를 한 번에 자동 기록
- 대표 퍼센트에 현재 사이클의 실현손익과 평가손익 합산
- 내 계좌 최상단의 전량매도·부분익절·보유·SGOV `지금 할 일` 카드
- 차트를 길게 누르고 드래그하는 날짜별 종가·SMA200 기준선
- 장중 퍼센트에 전일 확정 종가 대비 등락률임을 직접 표시
- 기존 부분익절 실현손익, 남은 원가, 평가손익과 익절 수량 계산
- 다른 해외주식 손익통산·250만원 공제·22% 예상세액
- 약 15분 주기의 백그라운드 확정 신호·부분익절 단계·장중 예비 경고 알림
- 첫 실행 4단계 사용 안내와 앱 안의 전체 전략 가이드북
- 그래프 우선 신호 화면과 상태별 파랑·청록·빨강·보라 색상
- 오조작 방지 확인창이 있는 부분익절 완료 단계
- 계좌 정보는 기기 안에만 저장

Android 소스와 빌드 방법은 [Android README](android/README.md)에 있습니다.

## 이전 웹 프로토타입

초기 검증에 사용한 Node.js 웹 프로토타입은 `public/`, `server.mjs`에 남아 있지만 현재 제품 대상은 Android 앱입니다. 웹 서버는 종료했습니다.

Node.js 20 이상에서 외부 패키지 설치 없이 실행됩니다.

```bash
npm start
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다.

테스트:

```bash
npm test
```

## 공통 구현 범위

- TQQQ 일별 종가 조회
- TQQQ SMA200 계산
- 상향 돌파, 3일 분할진입, 보유, 하향 이탈 상태 판정
- SPYM·SGOV 현재 달러 가격 조회
- 추가 현금 등록 시에만 USD 금액과 당시 USD/KRW 환율 기록
- 달러 기준 계좌 평가수익률
- 완료한 익절 단계를 제외한 다음 매도수량 계산
- Android 기기 로컬 계좌정보 저장
- 라이브 데이터 실패 시 마지막 성공 데이터 표시
- 캐시도 없으면 신호 생성 중단

라이브 데이터는 현재 Yahoo Finance의 비공식 Chart API를 사용합니다. 실제 서비스 전에는 신뢰할 수 있는 정식 데이터 공급자로 교체해야 합니다.
